# NASA Branding Implementation Guide

## NASA Official Branding Standards

### Primary Colors (NASA Brand Guidelines)
- **NASA Blue**: `#0B3D91` - Primary brand color, represents NASA's identity and space exploration
- **NASA White**: `#FFFFFF` - Secondary color, used for contrast and clarity
- **NASA Gray**: `#4A4A4A` - Used for text and supporting elements
- **NASA Light Gray**: `#E8E8E8` - Background and borders

### Secondary Colors (From NASA Web Design System)
- **Space Black**: `#1a1a1a` - Deep blacks for text and emphasis
- **Accent Gold**: `#D4A574` - Accent color representing scientific achievement
- **Accent Red**: `#C60C30` - Used sparingly for alerts and important messages
- **Success Green**: `#06A77D` - For positive feedback and success states

### Typography
- **Primary Font**: 'Trebuchet MS', Verdana, Arial, sans-serif
  - NASA's official web font stack
  - Professional, modern, accessible
  - Used for headings and body text
- **Fallback Stack**: Arial, sans-serif
- **Font Weights**: 
  - Normal (400): Body text
  - Bold (700): Headings

### Sizing Guidelines
- **H1 (Main Title)**: 40px on desktop, 28px on mobile
- **H2 (Modal Title)**: 28px on desktop, 22px on mobile
- **H3 (Card Title)**: 18px
- **Body Text**: 16px
- **Small Text**: 14px
- **Caption Text**: 12px

### Spacing & Layout
- **Container Max-Width**: 1200px
- **Padding Standards**: 
  - Large: 30px (desktop), 20px (tablet), 15px (mobile)
  - Medium: 20px (desktop), 15px (tablet), 10px (mobile)
  - Small: 10px (desktop), 8px (tablet), 5px (mobile)
- **Gap Standards**: 20px (desktop), 15px (mobile)

### Button Styling (NASA Standards)
- **Primary Button**: NASA Blue background (#0B3D91), white text
- **Hover State**: Darker blue (#062560) or accent gold border
- **Disabled State**: Gray background (#BFBFBF), reduced opacity
- **Padding**: 12px 20px on desktop, 10px 15px on mobile
- **Border Radius**: 4px
- **Font Size**: 16px

### Shadow & Depth (Material Design Alignment)
- **Elevation 1** (Cards): 0 2px 8px rgba(0, 0, 0, 0.15)
- **Elevation 2** (Hover): 0 4px 16px rgba(0, 0, 0, 0.25)
- **Elevation 3** (Modal): 0 10px 40px rgba(0, 0, 0, 0.3)

### Accessibility Standards
- **Minimum Contrast Ratio**: 4.5:1 for normal text, 3:1 for large text
- **Focus Indicators**: Blue outline (2px solid #0B3D91)
- **Color should not be only indicator**: Use icons, text, or patterns
- **Font Size Minimum**: 16px for body text to prevent zoom

### Loading & Interaction States
- **Loading Indicator**: Animated spinner with NASA Blue
- **Hover Effects**: Subtle color shift or scale transformation
- **Focus States**: Clear keyboard focus indicators
- **Active States**: Darker or contrasting color
