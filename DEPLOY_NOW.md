## Troubleshooting

| Problem | Solution |
|---------|----------|
| "Permission denied" | Ensure GitHub PAT has `repo` scope |
| Deployment fails | Check Actions tab for error logs |
| 404 after deployment | Refresh browser, clear cache (Ctrl+F5) |
| Images don't load | Check browser console (F12 > Console) |
