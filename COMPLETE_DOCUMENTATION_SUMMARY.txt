QUICK REFERENCE - YOUR NASA APOD API
═══════════════════════════════════════════════════════════════════════════════

API ENDPOINT:
  https://api.nasa.gov/planetary/apod

QUERY PARAMETERS:
  api_key=YOUR_KEY           (Required - your NASA key)
  start_date=YYYY-MM-DD      (Optional - range start)
  end_date=YYYY-MM-DD        (Optional - range end)
  date=YYYY-MM-DD            (Optional - single day)
  count=10                    (Optional - random 10 images)

DATE FORMAT:
  YYYY-MM-DD (ISO 8601)
  Example: 2024-11-01
  Range: June 16, 1995 to today
  No future dates allowed

RESPONSE FIELDS:
  date ............... Image date (YYYY-MM-DD)
  title .............. Image name/title
  explanation ........ NASA's detailed description
  url ................ Standard resolution image
  hdurl .............. High resolution image
  media_type ......... "image" or "video"
  copyright .......... Photo credit

RATE LIMITS:
  50 requests per hour
  5 requests per second
  Your app needs ~1 per click (easily within limits)

ERROR CODES:
  400 Bad Request ............... Check date format
  401 Unauthorized .............. Verify API key
  404 Not Found ................. Date is in future
  500 Server Error .............. NASA server issue

HOW YOUR APP WORKS:
  1. User selects dates + clicks button
  2. App sends API request to NASA
  3. NASA responds with image data (1 per day)
  4. App displays in responsive gallery
  5. User clicks image to see modal
  6. Modal shows HD image + full explanation

YOUR APP'S COMPLETE API FLOW
═══════════════════════════════════════════════════════════════════════════════

USER CLICKS "GET SPACE IMAGES"
        ↓
VALIDATE DATE INPUTS
        ↓
BUILD API REQUEST URL:
  https://api.nasa.gov/planetary/apod
  ?api_key=YOUR_KEY
  &start_date=2024-10-25
  &end_date=2024-11-01
        ↓
SEND HTTP GET REQUEST TO NASA
        ↓
SHOW "Loading..." MESSAGE
        ↓
RECEIVE JSON RESPONSE ARRAY
  [
    { date: "2024-10-25", title: "...", url: "...", hdurl: "...", ... },
    { date: "2024-10-26", title: "...", url: "...", hdurl: "...", ... },
    ...
  ]
        ↓
PROCESS EACH OBJECT:
  ├─ Check media_type
  ├─ If "image" → create gallery card
  └─ If "video" → show video link
        ↓
CREATE HTML FOR EACH IMAGE:
  ├─ Use "url" for thumbnail
  ├─ Store "hdurl" for modal
  ├─ Display "title"
  └─ Display "date"
        ↓
ADD TO PAGE (replacing placeholder)
        ↓
ADD CLICK HANDLER TO EACH CARD
        ↓
USER CLICKS IMAGE CARD
        ↓
MODAL OPENS WITH:
  ├─ "hdurl" as full-size image
  ├─ "title" as heading
  ├─ "date" as subtitle
  ├─ "explanation" as full text
  └─ Close button or ESC to close

COMMON QUESTIONS & ANSWERS
═══════════════════════════════════════════════════════════════════════════════

Q: What date format do I use?
A: YYYY-MM-DD (ISO 8601)
   Example: 2024-11-01
   See: API_CHEAT_SHEET.md or APOD_API_GUIDE.md

Q: How many images will I get?
A: 1 per day in your date range
   8-day range = 8 images
   See: APOD_API_GUIDE.md → "Response Limits"

Q: Can I get videos?
A: Yes! media_type field indicates "image" or "video"
   Your app already handles both
   See: API_INTEGRATION_DIAGRAM.md → "Separate images from videos"

Q: What's my rate limit?
A: 50 requests per hour, 5 per second
   Your app makes 1 per click (safe!)
   See: API_CHEAT_SHEET.md or APOD_API_GUIDE.md

Q: Why isn't my API key working?
A: Verify it at https://api.nasa.gov/
   Check for typos
   See: API_KEY_SETUP.md → "Troubleshooting"

Q: What if my date is in the future?
A: API returns 404 error (not allowed)
   Use dates up to today
   See: API_CHEAT_SHEET.md → "Common Errors"

Q: How does my app get images?
A: See: API_INTEGRATION_DIAGRAM.md → "Complete Flow"
   Shows exact process with examples

Q: What fields are available?
A: date, title, explanation, url, hdurl, media_type, copyright
   See: API_CHEAT_SHEET.md → "Response Fields"
   Or: APOD_API_GUIDE.md → "Response Fields"

QUICK TROUBLESHOOTING
═══════════════════════════════════════════════════════════════════════════════

Images not showing?
→ Check console (right-click → Inspect → Console tab)
→ Check API key is correct
→ Verify date format: YYYY-MM-DD
→ See: API_CHEAT_SHEET.md → "Troubleshooting"

Getting 401 error?
→ API key is wrong or expired
→ Get new key at https://api.nasa.gov/
→ See: API_KEY_SETUP.md

Getting 400 error?
→ Date format is wrong
→ Use YYYY-MM-DD only
→ Check start_date is before end_date
→ See: API_CHEAT_SHEET.md → "Common Errors"

Getting 404 error?
→ Date is in future (not allowed)
→ Try a date up to today
→ See: API_CHEAT_SHEET.md → "Common Errors"

Empty response?
→ Your date range might have no data
→ Try a different range
→ See: APOD_API_GUIDE.md

Need help?
→ Read: API_DOCUMENTATION_INDEX.md → "Common Questions"
